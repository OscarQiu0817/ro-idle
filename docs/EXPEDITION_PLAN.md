# 遠征模式（Roguelite）規劃（T65）

> 使用者 2026-11-21：任務目標、end game 太薄；打怪臨場感不夠；資料庫是 RO，裝備卡片都有固定解，只是時間早晚；放置遊戲重現不了 mob AI，沒有技術成分。
> 喜歡的方向：ro-survivor 的割草爽感、自走棋的機率強化、抽卡遊戲的陣容搭配 → 合成 Roguelite。

## 定位

| 項目 | 主線（現有） | 遠征（新） |
|---|---|---|
| 成長 | 永久：等級、裝備、卡片 | 每場重來；只帶走遠征貨幣與解鎖 |
| 隨機性 | 低（RO 資料固定） | 高：每場強化、卡片、規則都不同 |
| 技術成分 | 幾乎沒有 | 選強化、設優先順序、組陣容 |
| 終點 | 練滿 | 沒有上限的層數＋週排行 |

主線不動，遠征是另一種模式；主線練得越強，遠征起點越高，但打得深靠的是當場的 build。

## 一場遠征的流程

1. 主城「遠征 NPC」報名：帶自己＋最多 2 名隊友（沿用 `ALLY_MAX`），角色數值照主線帶入。
2. 進入獨立地圖（比照攻城：`map.arena`、不能趕路傳送、只能按「離開」）。
3. 每一層＝數波怪：一群一群衝過來，最後一波有菁英或首領。
4. 清完一層：**三選一強化**（必拿一個）；每 5 層一次「卡片抽選」或「商店」。
5. 倒光（沒有復活）或主動撤退 → 結算：依最高層數給遠征貨幣、更新紀錄。

## 系統

### 1. 割草（臨場感）
- 怪物成群出現：一波 10～30 隻，從畫面外往玩家衝。
- 近戰普攻有「前方扇形」範圍，一刀可以打多隻；遠程有穿透、魔法本來就是範圍。
- 連殺計數：短時間內擊殺累積，畫面顯示「×15 連殺」；越高掉落越好、音效越高。
- 怪物資料照用 RO（外觀、屬性、種族、體型），但血量、攻擊依層數重新縮放，不吃原本的 Lv。
- 怪的 AI 只要「衝過來、近身打、遠程站樁射」三種；首領沿用 `js/boss_*` 的技能。

### 2. 三選一強化（自走棋感）
- 每層結束隨機給 3 個，稀有度：一般／稀有／傳說。
- 類型舉例：
  - 普攻：三連擊、擊殺時爆炸、每第 5 下必暴擊、扇形變 360 度
  - 技能：某技能附帶屬性、冷卻 -30%、施放兩次
  - 生存：擊殺回血、受傷時 10% 機率無敵 1 秒
  - 經濟：本場掉落 +、商店打折
- 同系列拿 3 個升級成進化版（例如三個「火」相關 → 全部攻擊附火＋燃燒）。
- 數值獨立設計，不直接套 RO 公式，避免一招打穿。

### 3. RO 卡片進抽選池（打破固定解）
- 每 5 層從 3 張隨機 RO 卡片挑 1 張，本場生效、不佔裝備洞。
- 卡片效果沿用 `CARDS` 的 bonus（引擎已經會算），所以 RO 資料還是核心，只是每場拿到的不同。
- 依層數決定稀有度：前面多是一般怪卡，越深越容易出 MVP 卡。

### 4. 陣容羈絆（抽卡感）
- 隊伍裡同系職業湊數給羈絆，例如：
  - 劍士系 ×2：全隊 DEF ＋
  - 魔法師系 ＋ 服事系：全隊回 SP 加快
  - 盜賊系 ×3：暴擊率大增
- 遠征專用隊友從轉蛋或遠征商店拿，主線的隊友也能帶。
- 換陣容 → 換羈絆 → 換打法，不再只有一套最佳隊伍。

### 5. 每週規則
- 每週固定一組全服相同的特殊規則（種子用週數算，不用雲端）：例如「怪物全部火屬性」「補品無效」「首領兩倍血、掉落兩倍」。
- 讓上週的最強 build 這週不一定行。

### 6. 永久成長（遠征貨幣）
- 結算給遠征貨幣：層數越深越多，連殺、每週規則加成。
- 用途：解鎖新強化進池、永久小加成（起始血量、第一次三選一變四選一）、外觀、遠征專用隊友。
- 不換主線的強力裝備，避免變成必刷。

### 7. 放置與離線
- 手動玩時自己挑強化。
- 掛機／離線：照玩家設定的優先順序自動挑（例如「攻擊 > 生存 > 經濟」、指定想湊的系列）。
- 離線結算：用戰力估算能打到第幾層，給打折的遠征貨幣（比照攻城反攻用戰力算勝率）。
- 技術成分＝怎麼設優先順序、怎麼組陣容，不需要一直盯著畫面。

## 任務與 end game 串接

- 每日／每週任務加遠征目標：「這週打到第 20 層」「一場拿 3 個火系強化」「連殺 50」。
- 挑戰型成就：不用藥水過第 10 層、只帶一種職業系、不拿任何卡片過第 15 層。
- 週排行：單機版先跟自己的歷史紀錄比＋假人排行（比照假人系統）；雲端排行要先問（見記憶：雲端功能先確認）。
- 公告：打破自己紀錄、打到第 N 層時用 `broadcast()` 跑馬燈。

## 主線也能先做的臨場感

不用等遠征，下面這些主線也受益：
- 打中短暫停頓（hit stop）、暴擊畫面微震、傷害數字依大小縮放
- 雙殺、三殺提示，連殺音效遞增
- 掉落物從怪身上噴出、飛向角色
- 怪物改成小群一起出現（現在近戰一次最多 `MELEE_MAX_MONSTERS` 隻）

## 風險

| 風險 | 對策 |
|---|---|
| 同時畫幾十隻怪的效能 | 先做原型量 FPS；怪物用精簡版（不跑完整主線怪物邏輯），參考 `tools/prof_tick.js` |
| 強化組合失衡 | 強化數值獨立一張表；做模擬工具跑隨機 build 看層數分布 |
| 跟主線搶時間 | 遠征貨幣不換主線強力裝備；主線照常掛機，遠征是主動玩 |
| 存檔 | 一場進行中的遠征不存檔，中斷就結算（比照攻城中斷放回主城） |

## 決定（使用者 2026-11-21）

| 項目 | 決定 |
|---|---|
| 角色數值 | 主線數值全部帶進遠征，當作局外成長 |
| 一場長度 | 最多 15 分鐘；看殺怪隻數，殺夠了提前打王 |
| 遠征貨幣 | 可以換轉蛋碎片、商城點數 |
| 主線臨場感 | 可以先做，不等遠征 |
| 版本 | 現在玩法定版為 v2；下一版（v3）在 `v3-dev` 分支開發，成熟後 `main` 凍結成 `v2` 分支、`v3-dev` 合併進 `main`。開發期間 `main` 只修 bug |
| 存檔 | v3 用新的存檔 key（`ro_idle_v3_…`），不轉換、不覆蓋 v2 存檔 |
| 雲端存檔 | v3 先關閉（同一個帳號會互蓋 v2 雲端存檔）；要開再另外決定 |

## 技能（使用者 2026-11-21 確認）

帶隊友時三選一不分人，選項本身標明給誰（自走棋升級棋子的感覺）：

| 項目 | 提案 |
|---|---|
| 技能池 | 每個角色自己的職業鏈技能（主線學過的） |
| 開場 | 每人只帶 1 招攻擊技（自己指定）＋普攻；輔助技照主線勾選自動放 |
| 三選一 | 選項例：「騎士：學會螺旋擊刺」「騎士：螺旋擊刺 Lv＋2」「祭司：治癒術變範圍」「全隊：普攻三連擊」 |
| 技能格 | 沿用攻擊技 4 格；滿了之後只出升級／強化，不再出新技能 |
| 技能等級 | 進場從 Lv1 起，靠三選一升；上限＝主線學到的等級（局外成長的一部分） |
| 隊友 | 沿用現有隊友 AI 與技能條件設定，不用另外操作 |

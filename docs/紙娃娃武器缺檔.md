# 紙娃娃武器缺檔

身體有圖。頭上、頭中、頭下只要有原檔就會疊。
下面職業沒有自己的武器夾，武器圖沿用轉生前的職業。

- lordknight
- highwizard
- sniper
- whitesmith
- assassincross
- highpriest
- paladin
- champion
- professor
- stalker
- creator
- clown
- gypsy

武器夾對不到種類，沿用父職：

- shadowchaser

攻擊動作跟武器走。第 80 號多半是法杖或劍，短劍有的職業在第 88 號。

幀上完全沒掛圖層、戰場上看不到武器的（2026-10-27）：

- 劍士女，雙手劍 `sword2`。圖檔裡有劍，但每一幀的圖層是空的。畫面上改播同一職業的單手劍 `sword1`。男劍士的雙手劍照常。
- 武僧男女、修羅男女，拳套 `knuckle`。圖檔幾乎是空的，幀上也沒掛圖層。

其餘武器至少有一個動作掛了圖層。二轉以上沒有自己的武器夾時，沿用上一列的父職，不算缺。

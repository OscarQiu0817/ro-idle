# 流派點法實跑（T9／2026-11-14）

工具：`tools/sim_monk.js`（武僧）、`tools/sim_builds.js <職業|all> [等級] [分鐘]`（其他職業；`MAPS=a,b` 指定地圖、`MAPL=等級` 挑地圖用的等級、`DETAIL=1` 印施放與打斷次數）。
做法：同一隻 Lv90 快取角色，攻擊技與被動觸發技先清空，只放入該流派的技能與攻擊格；輔助照職業常用的勾。數字是每秒經驗，單人、每張圖 2～3 分鐘，變異約 ±20%。

## 冰雷偏弱的原因

- 火系有兩招被動觸發地面技（火焰之壁、火柱攻擊），不耗 SP，2 分鐘自動放 43 次，是主要輸出。冰雷系只有冰凍術（受擊觸發）；霜凍之術要被包圍才放，實跑一次都沒觸發。
- 箭系 Lv10 詠唱 7 秒（官方），單人掛機一直被打斷；火系主力火球術詠唱 1.5 秒。

可能的調整方向（待使用者決定）：冰刃之牆／霜凍之術的觸發條件放寬、箭系依被打斷情況自動降等施放、或提高冰雷的被動觸發機率。

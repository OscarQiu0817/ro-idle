# PVP 爬塔（規劃）

類似吉芬魔法大賽的 1 對 1 淘汰賽：一層一位關主，一路往上打。關主是模擬的角色資料，不是真玩家。

## 決定（使用者 2026-11-06）

| 項目 | 決定 |
|---|---|
| 關主實作 | A：人形怪物（角色資料換算成怪物數值，走現有打怪流程） |
| 人數 | 單人，不能帶隊友 |
| 次數 | 每天 3 次挑戰 |
| 形式 | 1 對 1 淘汰賽 |

## 規則

- 一層一場 1 對 1，限時 60 秒；HP 歸零或超時＝失敗，這次挑戰結束（淘汰）
- 開打前 HP／SP 補滿；連勝往上時不回滿（續戰要靠藥水）
- 一次挑戰從「目前最高樓層所在區段的起點」開始，失敗算掉一次
- 每天 3 次，跨日重置（本機時間）
- 塔內不掛機：切走分頁＝放棄這場，不進離線結算
- 進度每角色獨立：最高樓層、今日剩餘次數

## 關主資料

```js
TOWER_FLOORS = [
  { floor: 1, id: 'tw_01', name: '…', job: 'swordsman', baseLevel: 10,
    stats: { str, agi, vit, int, dex, luk }, equip: { weapon, armor, … }, cards: [],
    skills: { sm_bash: 5 }, ai: 'melee' | 'caster' | 'support', hair: 3, hairColor: 2, line: '台詞' },
  …
]
```

- 一般層：職業模板 × 樓層換算等級（1 層 ≈ Lv10，100 層 ≈ Lv200），素質照該職業常見配點，自動配該等級取得得到的裝備
- 每 10 層頭目關主：手寫，原創名字、招牌技能、一句台詞
- 外觀：現有職業圖（`images/frames`）＋髮型髮色

## 人形怪物換算

- 用跟玩家同一套公式（`recomputeDerived` 的算法）算出 HP、ATK／MATK、DEF／MDEF、HIT／FLEE、ASPD、屬性
- 輸出成 MONSTERS 格式的臨時怪物，`isBoss` 視情況開（免疫部分控場）
- 技能對應到 `monster_skills.js` 現有的怪物技能（例：騎士 → 連刺攻擊）；沒有對應的就只普攻
- 戰鬥畫面用人物圖而不是怪物圖

## 獎勵

- 每層首次通關：鋅幣、經驗；每 10 層：卡片／稀有材料／塔幣（可與 T10 點數合併）
- 頭目層：稱號或外觀頭飾
- 紀錄只跟自己比（無伺服器）

## 分階段

1. 原型：資料格式、換算、10 層、每日 3 次、通關紀錄、獎勵
2. 加深：頭目關主、技能對應、更多樓層、獎勵表
3. 可選：B 真角色對打；拿玩家其他欄位的角色當關主（打分身）

## 未決

- 淘汰後當天剩餘次數能不能從更低層重來
- 是否禁用某些道具（例：葉子、藥水上限）
- 樓層總數、等級曲線

# 打王戰鬥模式＋吉芬魔法大賽副本 規劃（2026-11-12）

使用者需求：把原型 `proto/bossview/` 的打王玩法接進遊戲，並做吉芬魔法大賽副本。兩者共用同一套「王戰」機制，先做打王模式，副本建在它上面。

## 現況

| 項目 | 現況 |
|---|---|
| 打王原型 | `proto/bossview/`（2026-11-06）：俯視、鏡頭跟玩家；五種預警（定點圓、扇形、直線衝鋒、腳下爆發、甜甜圈）；隊員看到預警後過「反應時間」走到最近的安全點，閃避途中不攻擊、詠唱中斷；祭司補血、倒地 3 秒復活 |
| 遊戲裡的王（改版前） | 玩家自己決定：地圖分頁有「MVP 模式」「迷你王模式」兩個開關，各自勾選；勾了之後那張圖有王的話，每次生怪約 20% 出王（MVP 只能在近戰模式開，因為帶小弟）。王跟一般怪一樣打，普攻＋pre-RE 技能表，沒有預警 |
| 遊戲的座標 | 怪是以玩家為原點的極座標 d／a（格），站位系統（2026-11-09）讓隊員有自己的位置，`shiftMonsters` 可換原點。原型用的是 x／y，換算沒問題 |
| 副本入口 | 每座城的「副本」區已有「副本管理員」NPC，目前 `role: 'soon'`（只顯示「還沒開放」） |
| 吉芬魔法大賽資料 | 官方怪物（geffen_mage_1～12、geffen_fenrir）在資料裡，但**不用**（使用者：只借名稱與形式）。道具可用：大賽硬幣、吉芬魔法袍［1］、吉芬魔法披肩［1］、防具／飾品附魔卷軸、12 精煉方塊 |

## 官方吉芬魔法大賽（參考）

- 單人副本，Base Lv90 以上，在吉芬找 NPC 報名
- 13 輪 1 對 1：12 名法師級對手，等級逐輪提高，最後一輪是潘利爾
- 每 3 輪出現治療師幫你補滿
- 限時 1 小時，冷卻約 1 天（各伺服器不同：16～23 小時）
- 每贏一輪拿硬幣，打越多輪越多；硬幣換大賽裝備與附魔卷軸

## 一、打王：地圖上挑戰＋解鎖＋時間結算（使用者 2026-11-12）

### 整體流程

1. **在那張地圖挑戰**（使用者 2026-11-12：不用去副本）：走到有王的地圖，地圖分頁（遇怪列表旁）列出這張圖的迷你王與 MVP，每隻一個「挑戰」按鈕。按下去當場開打：場上的小怪清掉、只剩王（MVP 帶小弟），畫面照原型的紅圈預警＋自動閃避；打完回到平常打怪。
2. **解鎖**：挑戰打贏某隻王，之後在這張圖平常打怪時牠才會出現（取代現在的「MVP 模式／迷你王模式」開關；沒解鎖的王在野外不會出現）。
3. **時間結算**：解鎖後在野外遇到這隻王，不再實際打一場，用「打王要花的時間」結算：
   - 王出現時，隊伍進入「討伐中」，這段時間不打別的怪
   - 時間＝這隻王的 HP ÷ 隊伍對牠的輸出（取最近一次挑戰的實際紀錄；隊伍或裝備變了就用現有估算重算）
   - 時間到直接拿王的經驗與掉落（MVP 經驗與 MVP 掉落照官方）
   - 離線結算同一條規則：王出現就扣這段時間、給這份獎勵——**打王本來就耗時，剛好拿來當結算**
4. **刷新紀錄**：已解鎖的王一樣有「挑戰」按鈕，再打一次、打得更快就縮短野外的結算時間（強化角色有感）。

### 挑戰的規則

| 項目 | 建議 |
|---|---|
| 開打 | 人在那張地圖、不在趕路或城裡；按鈕旁顯示王的等級與上次紀錄 |
| 次數 | 不限次數；掉落見待決定 1（避免無限刷王掉落） |
| 失敗 | 全隊倒地或超過時限（迷你王 3 分鐘、MVP 10 分鐘）就失敗，不扣經驗 |
| 隊伍 | 用目前的隊伍（含站位），跟野外一樣 |
| 重打 | 已解鎖的王也能重打刷新紀錄 |

### 打王模式機制（照原型）

| 項目 | 做法 |
|---|---|
| 預警技能 | 地上先畫紅圈，倒數結束才結算傷害 |
| 王的技能表 | 新增 `js/boss_patterns.js`：每隻王一份「技能輪替＋形狀＋傷害（最大 HP 的 %）＋預警秒數」。沒有寫的王用通用技能（下表） |
| 自動閃避 | 隊員看到自己在紅圈裡，過反應時間後走到最近的安全點。閃避途中不普攻、詠唱中斷 |
| 反應時間 | 原型是固定滑桿。正式版建議：基本 600ms，隨 AGI／DEX 縮短（例：每 10 點 −20ms，下限 250ms），讓素質有意義 |
| 誰會被打 | 紅圈打到所有站在裡面的人；站位系統照用：前排吃王的普攻 |
| 畫面 | 紅圈畫在地上（現有場地魔法圈的畫法可以沿用），王頭上顯示技能名與倒數條 |

### 通用技能（迷你王、沒有專屬技能表的 MVP）

參考 RO Idle 這類放置遊戲的做法：

| 技能 | 紅圈 | 效果 |
|---|---|---|
| 衝撞 | 王到目標的直線，寬 2 格 | 倒數後王衝過去，路上的人受傷並被擊退 |
| 彈跳 | 目標腳下的圓（半徑 2～3 格） | 王跳起、倒數後落在圓心，圓內受傷（可附暈眩） |
| 連環轟炸 | 隊伍周圍同時出現 3～6 個小圓 | 一定秒數後一起爆炸，站在任何一個圈裡都受傷 |
| 橫掃 | 王前方扇形 | 倒數後揮擊（MVP 才有） |
| 震地 | 甜甜圈或王身邊的大圓 | MVP 才有；貼近或遠離才安全 |

迷你王帶前三招；MVP 五招全有，熱門 MVP 再做專屬技能表。

## 二、吉芬魔法大賽副本

使用者 2026-11-12：**只借官方的名稱與形式（一輪一輪打、最後打王）**，不用官方那 13 隻怪物。畫面跟原型 `proto/bossview/` 一樣：對手是用紙娃娃畫的**虛擬角色**，他們放技能也會先畫紅圈。

### 虛擬對手

| 項目 | 做法 |
|---|---|
| 外觀 | 紙娃娃（職業、性別、髮型、髮色、頭飾、武器），跟原型的隊伍同一套 `paperdollPartsFor` |
| 職業與技能 | 每個對手一個二轉／進階二轉職業，帶 2～4 招該職業的招牌技能，每招對應一種紅圈形狀（下表） |
| 數值 | 依輪次用本作的角色公式造（等級、素質、裝備等級），不用官方怪物數值；可直接沿用模擬工具造角色的那一套（`tools/sim_party.js` 的 member 搬進遊戲） |
| 行為 | 跟原型的王一樣：追最近的人、射程內普攻，技能冷卻到了就放（先畫紅圈、倒數、結算）；遠程職業會保持距離 |
| 跟 PVP 爬塔共用 | T26 的關主也是「角色資料換成對手」，兩邊共用同一個虛擬角色產生器 |

技能 → 紅圈形狀（先做這批，之後再補）：

| 職業 | 招牌技能 | 紅圈 |
|---|---|---|
| 騎士 | 怪物互擊、連刺攻擊 | 扇形（前方） |
| 十字軍 | 聖十字審判 | 腳下爆發（自己身邊） |
| 巫師 | 暴風雪、隕石術 | 定點圓（打你腳下，倒數長、範圍大） |
| 賢者 | 火球術 | 定點圓（小） |
| 獵人 | 箭雨 | 定點圓；鷹爆：小圈 |
| 刺客 | 音速投擲 | 直線衝鋒（衝到你面前） |
| 武僧 | 阿修羅霸凰拳 | 直線（長、窄，倒數長） |
| 祭司 | 十字驅魔、光耀之堂 | 腳下爆發；會補自己 |
| 鐵匠 | 大地之擊 | 甜甜圈外圈 |
| 詩人／舞孃 | 歌曲 | 不放紅圈，給同場對手加增益（後期輪次才出現搭檔） |

### 輪次

| 輪次 | 對手 | 說明 |
|---|---|---|
| 1～3 | 一名二轉對手，1～2 招 | 熟悉紅圈 |
| 4～6 | 一名二轉對手，3 招 | 第 3 輪後治療師補滿 |
| 7～9 | 兩名對手（例：坦＋法系） | 紅圈同時出現 |
| 10～12 | 一名進階二轉對手，4 招 | 倒數變短 |
| 13（王） | 冠軍：進階二轉、5 招輪替、HP 很高，走打王模式 | 名稱可沿用「潘利爾」當冠軍稱號 |

對手職業每天輪換（照日期決定），同一天大家遇到的一樣，方便比較。

### 流程

1. 吉芬「副本」區的副本管理員報名（其他城的副本管理員顯示「吉芬魔法大賽在吉芬舉行」）。
2. 進入競技場（獨立地圖，畫面照原型：俯視、鏡頭跟玩家，不刷一般怪、不能用傳送）。
3. 一輪一場，打贏進下一輪；第 3、6、9、12 輪結束後治療師補滿 HP／SP。
4. 隊伍全倒或時間到（建議 30 分鐘）就結束，照打到的輪數結算硬幣。

### 單人還是組隊

官方是單人。本作的核心是三人隊伍，建議允許組隊，但硬幣依人數調整（例：單人 ×1.5、兩人 ×1.2、三人 ×1.0），讓單人挑戰有誘因。

### 次數與獎勵

| 項目 | 建議 |
|---|---|
| 次數 | 每天 1 次（每個角色），跟 PVP 爬塔（T26）的每日次數同一套 |
| 硬幣 | 每輪 1～3 枚、越後面越多；打完 13 輪再加獎勵 |
| 兌換 | 大賽 NPC 賣吉芬魔法袍、吉芬魔法披肩、12 精煉方塊；附魔卷軸要等附魔系統（D7） |
| 首通獎勵 | 第一次打完 13 輪送一次商城點數（接 T10） |

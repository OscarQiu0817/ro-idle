# 技能放置適性盤查（2026-11-11）

使用者需求：找出主動技在放置（自動施放）下發揮不了的，適度改成被動。只看二轉與進階二轉（一轉技能幾乎都有用）。

## 方法

- 工具：`tools/sim_skill.js`（本機，不進版控），結果 `tools/reports/skill_solo*.jsonl`、整理表 `tools/reports/skill_solo_report.txt`。
- 單人實跑：真的跑 `gameTick()`，假時鐘每 100ms 一拍，每次 1.5 分鐘。
- 13 個二轉職業 × 二轉 Lv60、Lv90 × 進階二轉 Lv60、Lv90；地圖挑怪物平均等級最接近的一張。
- 角色：技能全點、照職業配點、商店買得到的最好裝（無卡片、無精煉），技能觸媒各 300 個。
- 每個檢查點跑：
  - 只普攻
  - 預設攻擊欄（4 格）
  - 攻擊欄只放某一招（每招一次）
  - 預設攻擊欄＋某一招輔助（每招一次）
- 另跑一份插劍魚卡的版本，只測有詠唱的技能。
- 限制：
  - 1.5 分鐘擊殺數不多，±20% 內當雜訊。
  - Lv90 選到的地圖偏硬，很多職業普攻只剩個位數，該欄倍數會被放大。
  - 單人時自己就站最前排，法系、補師一直挨打，打斷次數比組隊時多。

## 結論一：系統性問題（不是個別技能）

| 問題 | 證據 | 建議 |
|---|---|---|
| 每隻怪都要重放的減益技會一直佔掉施放時間 | 鐵匠勾大地之擊：每 1.5 分 75 次，經驗剩 0.23 倍。流氓勾施毒 81 次，剩 0.28 倍。騎士勾挑釁 25 次，剩 0.76 倍 | 減益技只在「目標身上沒有這個效果、而且抗性不是免疫」時放；或改被動 |
| 輔助技優先施放，把攻擊技擠掉 | 先前組隊模擬：刺客勾施毒（不是塗毒）後，施毒 40 次、音速投擲 0 次；祭司勾十字驅魔後，光之打擊 0 次。塗毒有持續時間，只放 1 次、不影響 | 輔助優先只套在增益與治癒，減益排在攻擊技之後 |
| 攻擊技被歸成輔助 | 施毒（tf_poison）是 ATK 120% 的攻擊＋機率中毒，類型 `poison_proc` 沒算攻擊類，只能當輔助勾，沒有冷卻就一直搶 | 歸到攻擊類、放進攻擊欄；盤點其他類型沒算攻擊的攻擊技 |
| 法系、補師站前排會一直被打斷 | 巫師 Lv70 前排 33 exp/s；騎士站前排時巫師 302 exp/s。插劍魚卡：十字驅魔 62→191、0→322 | 組隊時預設站位依職業排（坦前法後）；戰鬥畫面提示「最近被打斷 N 次，建議換後排或插劍魚卡」 |
| 射程短的技能，遠程職業很少放得出來 | 獵人陷阱射程 3 格，拿弓停在約 9 格外。Lv60 幾乎放不出來（怪走到前就被打死）；Lv90 怪較耐打，每 1.5 分 3～23 次。經驗約 1.0 倍：不拖累、也沒幫助 | 調整施放時機：怪朝玩家移動時就布在牠的路徑上（RO 是事先布陷阱），不必改被動 |

## 結論二：改被動候選

施毒、陷阱不在此列（見結論一：歸類錯誤、施放時機），使用者 2026-11-11 指出：施毒改「普攻機率中毒」會跟塗毒重複；陷阱在怪靠近時放得出來。

| 技能 | 職業 | 實測 | 問題 | 建議被動化 |
|---|---|---|---|---|
| 挑釁 | 騎士、十字軍 | 0.76 倍（每 1.5 分 25 次） | 每隻新怪都重放 | 「攻擊時降低目標 DEF」被動，數值照挑釁等級 |
| 卸除頭盔／盾牌／鎧甲／武器、所有卸除 | 流氓、神行太保 | 0.01～0.28 倍 | 一直卸，幾乎不打 | 合併成「攻擊時機率卸除」被動（rAthena 本來就有卸除觸發的裝備） |
| 大地之擊 | 鐵匠 | 0.23 倍（75 次） | 範圍暈眩每隻都放 | 「普攻機率範圍暈眩」被動，或只在 3 隻以上時放 |
| 衝鋒箭 | 弓箭手系 | 0.5～0.8 倍 | 擊退把怪推遠，又要重新走過去 | 放置版拿掉擊退，或改成「普攻機率擊退」被動 |
| 元素更換（4 屬）、魔法效果解除 | 賢者、智者 | 0～0.15 倍 | 每隻怪都換，換完又死 | 「攻擊時機率把目標改成弱點屬性」被動，或只對首領放 |
| 緩速術、沉默之術、天使之怒 | 祭司、武僧 | 0 倍 | 降速、沉默在放置下沒有收益；天使之怒只對不死、惡魔有效 | 緩速術、沉默術：從自動施放清單拿掉。天使之怒：只對不死、惡魔種族放 |
| 石化術、精神撼動、易燃之網、HP 轉換 | 法系 | 0 倍 | 一直放、沒有傷害收益 | 從自動施放清單拿掉 |
| 眨眼之誘、驚聲尖叫、陣痛之聲 | 詩人、舞孃 | 0.5～0.86 倍 | 控場在放置下沒收益 | 從自動施放清單拿掉，或改被動 |
| 急救術 | 全職業 | 0.6～0.9 倍 | 補很少、一直放 | 只在 HP < 30% 時放 |

## 結論三：放置下運作良好（不用動）

- 物理主攻技：
  - 騎士：怪物互擊、螺旋擊刺、衝鋒攻擊
  - 十字軍：迴旋盾擊、連續盾擊（要站後排或插劍魚）
  - 刺客：音速投擲、黑暗瞬間
  - 流氓：背刺
  - 獵人：二連矢、箭雨、銳利射擊
  - 鐵匠：金錢攻擊、手推車終結技
  - 鍊金：火煙瓶投擲、氣泡蟲召喚
- 魔法主攻技：
  - 有效：崩裂術、聖靈召喚、火之獵殺、冰凍術、火球術、心靈爆破
  - 單人時被打斷到幾乎打不出傷害（每 1.5 分 7～8 次）：暴風雪、隕石術、怒雷強擊、雷爆術、地震術，插劍魚卡有改善；組隊站後排就正常
- 增益效果明顯：
  - 速度激發：3.0 倍
  - 魔力增幅：2.6 倍
  - 聖音：2.5 倍
  - 長矛加速術：2.1 倍
  - 經驗值倍增：1.3 倍
  - 歌曲大多 1.0～1.2 倍，符合預期
- 已經是被動、不用處理：武僧連段、阿修羅、氣功，流氓偷竊、強奪、二刀，刺客左右手修練

## 下一步

1. 先修系統性問題：減益技施放條件、輔助優先的範圍、施毒歸類、陷阱布置時機、預設站位、打斷提示。這一步就會讓大部分候選技能不再拖累輸出。
2. 修完重跑 `tools/sim_skill.js`，剩下仍然拖累輸出的再改被動。
3. 改被動的技能：說明文字照放置版寫，並註明跟官方的差異。

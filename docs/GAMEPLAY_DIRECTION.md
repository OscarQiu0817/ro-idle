## D1 空間模型

- 玩家是座標原點；每隻怪記距離 d（格）與方向角 a，出生時決定方向，之後沿該方向直線走向玩家
- 怪的移動仍是一維（只改 d）；方向角參與範圍與場地技判定
- 畫面上怪的位置必須與模擬一致（方向角不再只是裝飾）；鏡頭跟著角色

| 能表達 | 做法 |
|---|---|
| 近戰／遠程 | 射程（格） |
| 範圍技 | 平面距離（餘弦定理）`√(d₁² + d₂² − 2·d₁·d₂·cos Δa)` |
| 火牆、陷阱等場地技 | 放在 (d, a)；牆寬 N 格蓋住的角度 ≈ N ÷ d |
| 擊退 | 沿怪自己的方向 d +N |
| 後退、躲王的範圍技 | 所有怪 d 同時 +N；只用於 Boss 戰，日常打怪不風箏 |

| 限制 | 處理 |
|---|---|
| 朝單一方向移動（靠近 A、遠離 B） | 日常不需要；Boss 戰需要時改為平移所有怪的座標 |
| 怪繞路、閃避障礙 | 不支援；怪一律直線接近 |
| 卡位、包夾 | 不支援 |

原型比較見 `docs/PROTO_COMBAT1D.md` 第二輪：純距離模型高估範圍技約 25～40%，弧形火牆比圓圈牆安全。

## D2 詠唱

| 項目 | 公式／規則 |
|---|---|
| 變動詠唱 | `CastTime × max(0, 1 − √((DEX×2 + INT) / 530)) × (1 − 裝備%)` |
| 固定詠唱 | `max(0, FixedCastTime + 固定秒數) × (1 − 最高單一%)` |
| 後延遲 | `AfterCastActDelay`，固定值先加、% 相加後一次套用 |
| 冷卻 | `Cooldown`，各技能獨立 |
| 打斷 | 詠唱中受到任何命中即中斷（官方規則，原型比較後維持）；不可中斷效果（劍魚卡等）與 `CastCancel: false` 免疫 |
| 智能施法 | 預估會被打斷就不放；做成自動戰鬥設定項（原型證實必要，見 `docs/PROTO_COMBAT1D.md`） |
| 遠程怪 | 不特別處理；靠縮短詠唱、不可中斷裝備應對 |
| 詠唱中 | 不普攻 |

- 現行 `skillCdFlat`（冷卻 ±秒）的魔改廢除，裝備回歸官方語意
- `test_sing` 分支的 `getSkillCastTime()` 與 vct/fct 分軌可參考，但資料來源改為 `skill_db.yml`

## 原型（工作 1）

**狀態**：第一輪完成，結果與待決事項見 `docs/PROTO_COMBAT1D.md`。

**目的**：確認一維距離＋詠唱打斷下，放置節奏與職業強弱是否成立；不行就只損失原型。

**範圍**

- Node 獨立程式，不載入 `engine.js`、不碰畫面
- 怪物：從 `mob_db_re.yml` 取 HP、攻擊、防禦、`WalkSpeed`、`AttackRange`、`AttackDelay`、`DamageMotion`
- 技能：從 `skill_db.yml` 取詠唱、固詠、後延遲、冷卻、射程、範圍、`CastCancel`、擊退
- 傷害公式先用簡化版，重點在節奏不在精確數值
- 場地技只做火牆一種，驗證「擋住近戰 → 詠唱不被打斷」

**驗證情境**：3 種職業 × 2 張地圖

| 職業 | 代表技能 | 要看的 |
|---|---|---|
| 騎士（近戰） | 怪物攻擊、連刺攻擊 | 與現行版本的擊殺速度差距 |
| 獵人（遠程） | 二連矢、陷阱 | 射程優勢是否明顯但不過頭 |
| 巫師（法系） | 雷爆術、火牆 | 打斷率；有火牆時是否能穩定輸出 |

**輸出指標**：每分鐘擊殺數、每分鐘承受傷害、詠唱打斷率、死亡次數。

**通過標準**（初訂，可調）

- 三職業每分鐘擊殺數差距在 2 倍以內
- 巫師不放火牆時打斷率明顯偏高，放了之後明顯下降
- 遠程職業承受傷害明顯低於近戰

# 道館（T53）

## 定案（使用者 2026-11-13）＋第一版（js/dojo.js）

| 項目 | 定案 |
|---|---|
| 隊友 | 可以帶 |
| 關數 | 5 關，**每關一隻 MVP**（使用者 2026-11-13）：難度照怪物編號（版本）分段——初級 1000～1199（經典王 13 隻）、中級 1200～1639（11 隻）、高級 1640～1799（研究所人形王、蘭特克力斯等 16 隻）、地獄 1800 以上（12 隻）；一場不重複抽 5 隻、照等級排，同一天同難度一樣 |
| 門檻與時限 | 初級 Lv60／15 分、中級 Lv80／20 分、高級 Lv99／25 分、地獄 Lv99／30 分 |
| 模擬（商店裝、無卡無精煉） | 初級 Lv90 隊 4 分全破；中級 Lv90 隊 20 分只過 2 關；高級轉生 Lv99 隊 19.7 分全破；地獄轉生 Lv99 隊 16.3 分全破（當天抽到的王偏弱） |
| 獎勵 | 一律用抽的：每過一關抽 1 次，全破加抽（初級 1／中級 2／高級 3／地獄 5）。獎品池：白色藥水 ×10 25%、天地樹芽 20%、神秘箱子 20%、藍色藥水 ×5 15%、天地樹果實 15%、道館代幣 5% |
| 代幣兌換 | 1 枚＝10 商城點數；之後開放高階裝備材料 |
| 其他 | 4 檔難度、每難度每天 1 次、怪不給經驗與掉落；數值照原本怪物（還沒用模擬調） |

以下是原始規劃。

私服常見的「道館／試煉」：進專屬地圖，一關一關打，打完拿獎勵。跟 T26 PVP 爬塔（1 對 1 虛擬角色）分開：道館打的是**魔物＋首領**，可以帶隊友。

## 建議規則

| 項目 | 建議 |
|---|---|
| 入口 | 普隆德拉道館 NPC（城內選單，跟吉芬大賽報名同一套） |
| 地圖 | 客製化競技場地圖（`arena: true`，不回血不回魔） |
| 隊伍 | 可帶隊友（跟大賽不同） |
| 難度 | 初級 / 中級 / 高級 / 地獄，4 檔 |
| 關數 | 初級 5、中級 7、高級 8、地獄 10 |
| 每關 | 一波小怪（清完）→ 每 5 關、最後一關是首領（用 T51 紅圈技能） |
| 時限 | 整場限時（初級 10 分 → 地獄 25 分），不是每關 |
| 關與關之間 | 不回滿；第 5 關後有一次補給 NPC（補滿 HP/SP） |
| 失敗 | 全滅／時間到／離開地圖＝結束，照**已打完的關數**給部分獎勵 |
| 次數 | 每難度每天 1 次（跨日重置，跟大賽同一套） |
| 開放條件 | 初級 Lv30、中級 Lv60、高級 Lv80、地獄 轉生後或 Lv99＋高級全破過 |

## 魔物與數值

- 小怪從現有 `MONSTERS` 依難度等級帶抽（初級 Lv20–40 … 地獄 Lv90+），每關同種族一組，有變化
- 首領：中級起用該等級帶的迷你王，地獄最後一關用 MVP（套 `boss_patterns.js` 專屬技能）
- 數值係數照大賽的作法：先用 `tools/sim_party.js` 模擬各職業，再定 HP／ATK 倍率；不弱化到人人打得完（裝備可以是門檻）

## 獎勵

每關固定小獎＋全破大獎；首次全破另送一次。

| 難度 | 每關 | 全破 | 首次全破 |
|---|---|---|---|
| 初級 | 白色藥水 ×3 | 天地樹芽 ×2、2 商城點數 | 20 商城點數 |
| 中級 | 天地樹芽 ×1 | 天地樹果實 ×1、5 商城點數 | 40 商城點數 |
| 高級 | 天地樹果實 ×1 | 天地樹果實 ×3、濃縮神之金屬／濃縮鋁 隨機 1、10 商城點數 | 60 商城點數 |
| 地獄 | 天地樹果實 ×2 | 天地樹果實 ×5、任一部位裝備轉蛋 ×1、20 商城點數 | 100 商城點數＋稱號 |

另一條：道館代幣（每關 1、全破加倍），在 NPC 換天地樹果實、轉蛋、精煉材料（跟吉芬硬幣同一套兌換介面）。
